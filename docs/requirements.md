> AI 코어 프로젝트 2회차 · RAG 기반 도메인 지식 서비스
> 도메인: **MLB 선수 기록과 세이버메트릭스** · 작성 2026-10-22

## 1. 도메인과 선택 조건 충족 근거

**서비스 한 줄 설명**: MLB 선수를 골라 질문하면 시즌 기록 · 위키백과 문서 · 지표 사전을 근거로 답하고, 답변에 인용한 근거를 원문 링크와 함께 보여 줍니다.

| 조건 (명세서 1.2) | 충족 근거 |
|---|---|
| **항목 메타데이터 약 100건 이상** | 1901~2025 시즌 AL · NL 출장 선수 19,200명 중 한국어 · 영어 위키백과 문서가 모두 있는 선수 **2,047명** (투수 954 · 타자 1,093). 선수마다 이름(한/영) · 투타 · 포지션 · 출생 · 출신 · 활약 기간 · 소속 구단 · 통산 기록 · 수상 · 포스트시즌을 가짐 (`players.json`) |
| **외부 문서 출처** | 선수마다 한국어 · 영어 위키백과 본인 문서 (한국어 2,047건 · 영어 2,058건, 질문 시 보충 수집 포함). 기록 데이터는 SABR Lahman Database에서 선수 × 시즌 · 팀 × 시즌 문서 26,302건으로 구성. 지표 사전 38개 직접 작성 |
| **출처와 이용 조건 기록** | Lahman CC BY-SA 3.0 · Chadwick ODC-By 1.0 · Wikidata CC0 · 위키백과 CC BY-SA 4.0 — README 5장(원천 · 수집/가공 데이터별 라이선스)에 기록, 화면 하단과 근거마다 출처 표시 |
| **근거가 필요한 질문** | 아래 2장 |
| **위험 도메인 여부** | 야구 기록은 건강 · 금융처럼 판단이 위험한 도메인이 아니므로 면책 문구는 두지 않음 |

**제외한 출처와 이유**: KBO 공식 사이트 · 스탯티즈(자동 수집 금지), Baseball-Reference · FanGraphs · Baseball Savant(대량 수집 · 재배포 제한), 니그로 리그 데이터(Lahman 안에서도 별도 라이선스).

## 2. 근거가 필요한 질문

근거 없이 답하면 그럴듯한 수치를 지어내기 쉬운 질문입니다. 실제로 같은 모델에 RAG 없이 물었을 때 틀린 예입니다 (`docs/rag_comparison.md`).

| # | 질문 | RAG 없이 | 정답 (근거) |
|---|---|---|---|
| 1 | C. D. 펠햄의 2018년 등판 수 · 이닝 · 평균자책점 · FIP는? | 9경기 · 9.1이닝 · 3.86 · 5.17 (모두 틀림) | 10경기 · 7⅔이닝 · 7.04 · 2.94 (Lahman 기록) |
| 2 | 2019년 다저스의 피타고리안 기대 승수와 실제 승수 차이는? | 약 +6승 | 기대 108.2승 · 실제 106승 · −2.2승 (팀 시즌 기록) |
| 3 | 클레이튼 커쇼의 2014년 승패는? | 18승 3패 | 21승 3패 (Lahman 기록) |
| 4 | A. J. 라모스 2015년 탈삼진 비율은? | 8.1 K/9 | 31.4% (K/9 11.13) |
| 5 | 오타니의 2023년 팔꿈치 부상은 언제 확인됐나? | "8월 24일경 경기 전 검사" | 8월 23일 경기 중 교체 후 UCL 파열 확인, 9월 19일 수술 (영어 위키백과) |

이처럼 세부 시즌 기록 · 계산 지표 · 덜 알려진 선수 · 구체적 사건 날짜는 근거가 있어야 정확히 답할 수 있습니다.

## 3. 기능 요구사항

### 3.1 필수 기능 (명세서 F2001 ~ F2012, 도메인에 맞게 표현)

| 번호 | 분류 | 요구사항명 | 요구사항 상세 (이 서비스) | 우선순위 |
|---|---|---|---|---|
| F2001 | 데이터 | 항목 메타데이터 적재 | 선수 2,047명을 로드하고 선수 1명을 하나의 색인 텍스트(이름 · 투타 · 포지션 · 출신 · 기간 · 구단 · 통산 기록 · 최고 시즌 · 수상 · 특징)로 구성한다 | 필수 |
| F2002 | 색인 | 메타데이터 색인 (RAG 1) | 색인 텍스트를 임베딩해 `player_meta`에 선수당 청크 1개로 넣는다. 청크 ID = 선수 ID라 다시 색인해도 덮어쓴다. 색인 건수를 화면에 표시한다 | 필수 |
| F2003 | 프롬프트 | 검색어 추출 (프롬프트 1) | MLB 기록 분석가 역할로 선수와 질문에서 검색어를 JSON 배열로 추출한다. 선수 본인 문서는 항상 검색 대상이다 | 필수 |
| F2004 | 수집 | 외부 문서 수집 (프롬프트 2) | 선수 본인 한/영 위키 문서는 사전 수집해 항상 색인한다. 근거가 부족하면 위키백과를 검색해 후보 제목 · 요약을 프롬프트 2로 선별하고 본문 · URL을 수집한다. 이미 수집한 검색어 · 문서는 다시 받지 않는다 | 필수 |
| F2005 | 색인 | 외부 문서 색인 (RAG 2) | 위키는 1,000자/200자로 청킹해 `player_docs`에 넣는다. 청크 ID = 항목ID:문서ID:순번, 청크에 제목 · URL · 관련 선수 · 출처 종류를 저장한다. 청크 크기 · 겹침은 설정으로 조정한다 | 필수 |
| F2006 | 검색 | 근거 검색 및 병합 | 선수 메타데이터는 항상 근거에 넣고, 외부 문서는 선수 범위 안에서 유사도로 검색해 병합 · 중복 제거한다. Top-k(기록 · 위키)는 설정으로 조정한다 | 필수 |
| F2007 | 생성 | 근거 기반 답변 생성 (프롬프트 3) | LangGraph retrieve · generate 2노드로 구성한다. 근거 문서의 내용만 사용하고, 근거에 출처 종류를 표시하며, 근거가 없으면 확인되지 않는다고 답한다 | 필수 |
| F2008 | 생성 | 근거 표시 | 주요 주장에 [근거 N]을 달고, 실제 인용한 근거만 제목 · 원문 링크와 함께 표시한다. 인용이 없으면 안내한다 | 필수 |
| F2009 | UI | 항목 선택 및 질의응답 | 선수를 검색해 선택하고 질문한다. 대화 기록은 선수(비교 시 조합)별로 유지된다 | 필수 |
| F2010 | 서비스 | 도메인 특화 기능 | ① 두 선수 비교 ② 사실 확인(참 · 거짓 · 일부 사실 · 근거 부족 판정) ③ 구단 시절 합산 — 모두 근거와 함께 제공한다 | 필수 |
| F2011 | 서비스 | 조건 기반 항목 탐색 | 자연어 조건("통산 홈런 400개 이상인 좌타자")으로 후보를 찾고 조건에 맞는 선수만 카드로 보여 준다. 카드를 누르면 그 선수 페이지에서 질문을 이어 간다 | 필수 |
| F2012 | UI | 진행 상태 및 안내 | 처리 중 · 문서 수집 결과 · 근거 수 · 소요 시간을 표시한다. 색인이 없거나 키가 없으면 안내 후 기록 검색 모드로 대신 답한다 (위험 도메인 아님 → 면책 문구 없음) | 필수 |

### 3.2 심화 기능 (명세서 F2013 ~ F2016)

| 번호 | 분류 | 요구사항명 | 요구사항 상세 (이 서비스) | 우선순위 |
|---|---|---|---|---|
| F2013 | UI | 프론트엔드 직접 구현 | Django 템플릿 + HTML · CSS · JS로 화면을 만들고, 화면과 서버를 JSON API로 분리한다 (Streamlit 대신) | 심화 |
| F2014 | 검색 품질 | MMR 검색 적용 | 위키 근거는 후보 30개 중 MMR(λ 0.7)로 4개를 고른다. 유사도 검색과의 차이를 CLI(`--search-compare`)와 RAG 실험실 화면에서 확인한다 | 심화 |
| F2015 | 품질 | RAG 전후 품질 비교 | 대표 질문 12개를 RAG 없이 / RAG로 비교한 문서 (`docs/rag_comparison.md`) | 심화 |
| F2016 | 수집 | 여러 문서 출처 결합 | 기록 데이터 · 위키백과(한/영) · 지표 사전을 함께 색인하고 근거에 출처 종류를 표시한다. 출처마다 청킹 방식을 달리한 이유를 설계문서에 적는다 | 심화 |

### 3.3 이 서비스에서 추가한 기능

| 번호 | 요구사항명 | 요구사항 상세 |
|---|---|---|
| A1 | 근거 원문 미리보기 | 인용한 근거의 청크 본문을 답변 아래에서 펼쳐 볼 수 있다 |
| A2 | RAG 실험실 | 청크 크기 · Top-k · 유사도/MMR · λ를 두 설정으로 나란히 실행해 근거 · 답변 차이를 본다 |
| B1 | 커리어 그래프 | 선수 페이지에 시즌별 OPS+ · ERA+ 등 추이와 리그 평균 기준선을 표시한다 |
| B2 | 비슷한 선수 | 통산 지표 6개의 표준화 거리로 커리어가 비슷한 선수 5명을 보여 준다 |
| B4 | 답변 스트리밍 | 근거 목록을 먼저 보여 주고 답변을 생성되는 대로 표시한다 |
| B5 | 시즌 타임라인 | 1901~2025 연도별 월드시리즈 우승 · MVP · 사이영상 · 부문 1위 (Lahman 전체 선수 기준) |

## 4. 비기능 요구사항

| 번호 | 분류 | 요구사항명 | 요구사항 상세 (이 서비스) |
|---|---|---|---|
| NF2001 | 성능 | 응답 시간 | 일반 질문 수 초 안에 근거 · 답변 시작(스트리밍). 보충 수집은 근거가 부족할 때만 |
| NF2002 | 성능 | 수집 캐시 | manifest로 검색어 · 문서 재수집 방지, 같은 본문은 다시 임베딩하지 않음 |

| NF2005 | 확장성 | 모듈 분리 | collect · build(데이터 준비) / rag(색인 · 검색 · 생성) / web(UI) |
| NF2006 | 품질 | 외부 API 예절 | User-Agent 연락처, 요청 간 대기, 429 · 5xx 재시도 |
| NF2007 | 법 · 윤리 | 출처와 이용 조건 | README 5장 · 화면 하단 · 근거별 원문 링크 |
